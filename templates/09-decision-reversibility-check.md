# Template 09 · Decision reversibility check

Use it when someone says it's a two-way door, so let's just decide. Based on `references/07-metrics-and-decisions.md`.
His claim is that "most doors that look like two-way doors are actually one-way doors" [L2 23:19]. The
questions and the scoring below are **our suggestion**, built on his QBR story [L2 18:34 to 23:19].

Decision: ______________________  Date: __________

## 1. The three fundamentals [L2 19:32]

| | Clear? (Y / N) | One line |
|---|---|---|
| Customer motivation | | |
| Differentiation | | |
| Distribution approach | | |

If any is N, this isn't ready to decide, whatever the door type.

## 2. What would undoing it really cost?

| Question | Little / Some / A lot |
|---|---|
| Who will depend on this within a quarter (customers, sales promises, other teams)? | |
| How much table-stakes work will follow once it ships? | |
| Would we really be allowed to remove it later? | |
| How much upkeep per quarter? | |
| What else does the team not do while building it (opportunity cost)? | |

**Our suggestion:** two or more “A lot” answers means treat it as a one-way door.
