> intentions are actually not execution problems, they are either strategy problems or interpersonal problems
> or cultural problems." [L1 00:54:49]

## Ask four questions

| Possible root cause | Question to ask | Evidence for | Evidence against |
|---|---|---|---|
| **Strategy** | Would two people on the team describe the strategy the same way? Does the strategy come up when we prioritize? | | |
| **Interpersonal** | Is there a pair of people who simply can't work together? | | |
| **Culture** | What do we actually reward (OKR hitting, visible activity, shipping dates)? | | |
| **Skills gap** (a real execution problem) | Does someone lack a skill the work needs? | | |
