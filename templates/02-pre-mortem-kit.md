## Before

- [ ] Invite the core team. For big launches, run a separate go-to-market pre-mortem [L1 00:30:07].
- [ ] Set up a shared doc with three columns (tiger, paper tiger, elephant) where entries can be private
      until the share-out. He uses a template doc for this [L1 00:30:35].
- [ ] **Our suggestion:** share the plan in advance so people come with context.

## 1. The prompt (read it out)

> "Imagine this project that we are working on has failed six months from now, or this launch we are doing
> has miserably failed." [L1 00:24:50] **Why did it fail?**

## 2. Quiet time

## 3. Vote on someone else's tiger

Each person picks "the tiger that they find more scary, but that somebody else mentioned." [L1 00:31:11]
(He describes one pick per person. **Our suggestion:** for groups over about ten, allow two picks each.)
