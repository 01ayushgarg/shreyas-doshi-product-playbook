# Template 02 · Pre-mortem kit (60 to 120 minutes)

Based on `references/02-pre-mortems.md`. "Pre-mortems literally take 1-2 hours." [X 2023-08-09]

Project / launch: ______________________  Date: __________  Facilitator: __________

## Before

- [ ] Invite the core team, plus someone from go-to-market for big launches (or run a separate GTM
      pre-mortem [L1 00:30:07]).
- [ ] Share the plan in advance so people come with context.

## 1. The prompt (read it out exactly)

> "Imagine this project that we are working on has failed six months from now, or this launch we are doing
> has miserably failed." [L1 00:24:50] **Why did it fail?**

Everyone writes silently for 10 minutes, one reason per sticky note.

## 2. Sort into three buckets

| Tiger (a threat that will actually kill us) | Paper tiger (others worry, you don't) | Elephant (nobody is talking about it) |
|---|---|---|
| | | |
| | | |

Definitions from [L1 00:27:14 to 00:27:51].

## 3. Vote

Each person votes for the scariest tigers, "the tiger that they find more scary, but that somebody else
mentioned." [L1 00:31:11] Two or three votes each.

## 4. Action plan for the top tigers

| Tiger | Votes | Mitigation | Owner | By when |
|---|---|---|---|---|
| | | | | |

"The point is not to solve every problem, the point is to identify threats that we are not talking about
openly." [L1 00:31:11]

## After

- [ ] Share the action plan with the whole team.
- [ ] The leader tracks it in the regular team review: "keep myself as the leader accountable for actually
      making progress on it." [L1 00:31:11]
